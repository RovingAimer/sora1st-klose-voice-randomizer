# 独立语音兼容模块

2026-10-20 当前实现与交付边界：用户已授权适配源码推送；本轮仅整理本地 options 候选，不创建正式 release，不操作游戏，也不上传音频。当前双声道使用同一播放任务中的两路原生单声道 SourceVoice，经内部双声道子混音分别送到左右声道并设置独立音量；默认左新版、右旧版，可交换。双声道不需要预合成素材包，现有 824 个旧版 WAV 保持原样。

源码静态证据显示停止/淡出和按句柄判断活动语音的路径覆盖同一任务句柄中的两路语音。旧语音缓存或第二路启动失败时回退为普通新版语音；第二路失败时已启动的新语音恢复为双侧输出和原音量。双头像只标示已选双声道模式，不证明两路成功，需结合听测与 NATIVE_STEREO_PAIR both=1 日志。详细单路时长和部分位置接口仍只取首路。游戏中实际左右输出、冷缓存、跳过、淡出以及双路结束等待仍待用户验收；不得称为实机通过。

- 本目录承接 VoiceRandomizerCompat 的兼容实现；产品源码入口为 source/，作者的 voice_randomizer/ 工程用于核对和维护。
- 配置编辑器源码已修改以支持新增字段，不能称新版编辑器二进制与原程序字节一致。build.py --editor 输出 KloseVoiceSettings.exe，打包名为“克萝赛MOD设置.exe”。
- 缺少新增 INI 键时使用模板默认值；软保底与双声道默认关闭。模块更新包为 DLL、sora_mod.ini 和新编辑器三文件，保留用户 voice_randomizer.ini；完整安装包为 832 个文件，含新默认 INI、编辑器、824 个旧版 WAV、4 张 PNG 和模块文件。
- 软保底在 random 模式累计连续未中目标次数，到 Start 后下次加 Step 个百分点；之后每再未中一次继续增加，最高 100%，命中目标清零。改变软参数只清软计数；目标、硬保底或捕获明光开关变化清全部规则计数。
- Overlay 最多保留最近 50 条。MaxEntries 只决定显示条数，不影响头像大小或间距；尺寸使用固定十条基准。HeightPercent 对应界面标签“UI 区域高度 (%)”，控制 UI 区域高度；CenterYPercent 对应“垂直中心 (%)”，保留垂直位置控制；超过十条时向上扩展并裁剪屏幕外部分。
- 非 random 模式暂停随机与保底计数，alternate 仍逐语音交替；双声道启用时优先播放两路语音，并暂停随机、逐语音交替及各类保底计数。LeftVolume/RightVolume 在配置重读后用于后续创建的 SourceVoice，不改变正在播放的语音。
