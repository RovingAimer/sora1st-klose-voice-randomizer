# 本地候选验收与回退

候选用于用户手动验收，目前没有游戏内通过结果。本地构建和 ZIP 核对不代表游戏运行通过；本次不自动安装、启动或操作游戏。仅在 sora_1st.exe SHA256 为 9585d3d993874d65156aba633c00b8a25faab3afde8953a8a183c80fb8f657ac 且已有 sora1looseload v0.2.0 的环境中验收。

## 安装准备

1. 退出游戏，备份 mods/VoiceRandomizer/ 下的 DLL 与 sora_mod.ini，以及 voice/wav/voice_randomizer/ 下的设置编辑器和个人 voice_randomizer.ini。特别保留原 DLL 与编辑器，供回退使用。保留游戏根目录的 xinput1_4.dll。
2. 已有兼容候选且旧素材完整时，解压 compat/dist/20261020-default-volume/VoiceRandomizer-options-candidate-module-update.zip 到游戏目录并按原路径合并。此包含 3 个文件：模块 DLL、sora_mod.ini 和新版设置编辑器，不包含或覆盖用户 INI。
3. 首次安装或需恢复完整旧素材时，使用同目录下的 VoiceRandomizer-options-candidate-install.zip。该包有 832 个文件，含新默认 INI、新设置编辑器、824 个旧版 WAV 和 4 张 PNG，以及模块文件。它会提供默认 INI；安装前备份个人配置，安装后恢复自己的 INI。
4. 不需要额外双声道素材包。双声道模式使用游戏新版单声道语音和已有旧版 WAV。

旧 INI 无需手工补齐字段；缺少新增键时模块使用默认值，软保底和双声道默认关闭。新版设置编辑器从修改后的作者源码重新构建，读取同目录 voice_randomizer.ini；保存会写入新增字段并保留其他已有设置。构建产物名为 KloseVoiceSettings.exe，安装包内名称为“克萝赛MOD设置.exe”。常规设置约 1 秒后重读并作用于后续播放；LeftVolume/RightVolume 在之后新建的 SourceVoice 上生效，不影响已经播放的语音。ReplacementSet 需要重启游戏。

## 手动验收顺序

| 顺序 | 设置与操作 | 观察内容 |
| --- | --- | --- |
| 普通规则 | 依次测试 Mode=new、old、random 和 alternate；random 下将 OldPercent 设为 0 与 100 | 检查原有新旧、随机和逐语音交替行为；缺少旧语音时是否按既有逻辑回退。 |
| 默认音量 | 双声道关闭、语音替换启用，设 VolumePercent=0、50、100，保存后等约一秒并分别触发新版与旧版克萝赛语音 | 0 静音、50 降低、100 恢复原音量；其他角色语音保持其原设置。开启双声道时默认音量输入框/微调按钮置灰，仅左右音量生效；关闭双声道后默认音量数值恢复使用。缺少此键的旧配置默认 100，不影响规则计数。 |
| 硬保底与捕获明光 | 分别单独启用硬保底和捕获明光，分别以 GuaranteeTarget=new/old 和相反的基础概率测试 | 检查原有触发次数、目标方向与触发后的计数行为。 |
| 软保底 | 设 Mode=random、关闭硬保底和捕获明光，设 SoftPityEnabled=1、SoftPityStart=2、SoftPityStep=10。以目标基础概率 50% 的配置连续触发 | 两次未中目标后，下一次目标概率为 60%；再未中，下一次为 70%。命中目标后计数清零。也可将目标基础概率设为 0%，前两次应未中、第三次目标概率为 10%。 |
| 规则计数 | 累计软保底未中后只改变软保底开关、阈值或步长；再分别改变 GuaranteeTarget、GuaranteeEnabled、CapturingRadianceEnabled | 软保底参数变化只清空软计数；目标或硬保底/捕获明光开关变化清空全部规则计数。非 random 模式暂停随机与保底计数，alternate 仍按语音名交替；双声道模式会暂停随机、交替及保底计数。 |
| Overlay | 播放多条语音，在 MaxEntries=1、10、50 间切换；另测透明度、歪标识缩放、UI区域高度、CenterYPercent 和 HideOnOtherVoice | 条数变化只改变显示数量；图标大小和间距不变。固定十条基准，超过十条从底部向上扩展，屏幕外上部裁剪。UI区域高度改变区域大小，CenterYPercent 改变垂直位置。成功播放 kind=2 的其他角色语音会隐藏 Overlay，克萝赛语音后恢复且历史不清空。 |
| 新版设置界面 | 打开新版“克萝赛MOD设置.exe”，编辑并保存软保底、Overlay 和双声道字段，再关闭并重开检查 | 检查新字段可读取，已有配置仍保留；检查 MaxEntries 变化不影响图标大小或间距。 |
| 双声道（最后） | 启用 Stereo，先设 LeftVolume=0、RightVolume=100 并播放；再设 LeftVolume=100、RightVolume=0；然后设 SwapChannels=1 重测。每次保存后等约 1 秒并触发一条新语音 | 按默认映射，左侧为新版、右侧为旧版；单侧静音时听到另一侧。交换后左右内容互换。记录出现双头像只表示双声道模式已选中，不证明两个声音均启动。结合听测和 NATIVE_STEREO_PAIR both=1 日志确认双路启动；用首次冷缓存语音重复测试，并检查跳过、淡出、停止及结束等待。 |

双声道在源码中的静态证据显示：同一个播放任务句柄会请求两路单声道 SourceVoice；每路被送入内部双声道子混音，并分别设置左右输出矩阵和音量。旧语音未能缓存或第二路未启动时会回退为普通新版语音；第二路失败时已启动的新语音恢复为双侧输出和原音量。源码也显示原有高层请求与游戏引擎播放路径仍在使用，停止/淡出和按播放句柄判断任一路仍活动的逻辑均覆盖该句柄的两路语音。

实机仍需确认左右声道在当前硬件和游戏场景中的实际映射、首次冷缓存行为、跳过/淡出，以及两路语音结束和等待条件。单路时长详情和部分位置接口目前只读取首路信息；在验证这些时序前，不将双声道记为通过。

## 回退

先退出游戏。使用 module-update.zip 时，恢复备份的 VoiceRandomizer.dll、sora_mod.ini 和“克萝赛MOD设置.exe”；用户 INI 未被更新包覆盖。若使用完整 install.zip，另外恢复安装前备份的 voice_randomizer.ini。旧版 824 个 WAV 和 4 张 PNG 在候选完整包中保留原内容。双声道不需要额外素材，回退时无需删除双声道资源目录。不要删除整个 mods/ 或 voice/ 目录，也不要修改根目录 xinput1_4.dll、其他 Mod 或游戏文件。
