# 安装检查与回退

v0.1.0 发布范围为用户已确认正常的普通语音规则、软保底、默认音量和播放记录选项。双声道界面与配置已移除；旧配置中的启用项被忽略。助手不安装或启动游戏。

## 安装

1. 退出游戏，备份 `mods/VoiceRandomizer/`，以及 `voice/wav/voice_randomizer/` 中的设置程序和 `voice_randomizer.ini`。
2. 已有兼容版使用 `VoiceRandomizer-v0.1.0-update.zip`，按原路径解压到游戏目录。只有模块 DLL、模块声明和新设置程序，不覆盖个人 INI。
3. 首次安装使用 `VoiceRandomizer-v0.1.0-main.zip`，含上述程序、默认 INI 和四张界面图片。旧语音素材需自行准备，放在 `voice/wav/voice_randomizer/assets/old/`。包内不含根目录加载器。
4. 使用新版设置程序修改配置。保存后约一秒读取，对之后播放的语音生效；素材分支切换需要重启游戏。

前提为通用加载器 v0.2.0。模块只接受 `sora_1st.exe` SHA256 `9585d3d993874d65156aba633c00b8a25faab3afde8953a8a183c80fb8f657ac`。

## 检查

- 普通模式：新版、旧版、随机和逐句交替，以及硬保底/捕获明光维持原规则。
- 软保底：关闭硬保底和明光后，连续未中 X 次，下一次目标概率加设定百分点；再未中继续增加，命中清零。
- 默认音量：测试 0、50、100，分别触发新版和旧版；其他角色保持原音量。
- 显示：切换条数时图标尺寸与间距不变；透明度 100 隐藏，歪标识独立缩放；其他角色语音时可隐藏，克萝赛语音时恢复。
- 旧配置：即使旧 `[Stereo] Enabled=1`，模块也只播放普通模式，默认音量可用；编辑器无双声道控件，保存后移除旧节并保留其他配置。

用户已确认保留功能正常。本次针对入口移除与旧配置迁移进行静态源码、编译、包内容与独立源码重编译核验；不将停用的双声道记为通过。

## 回退

退出游戏，恢复备份的语音模块、设置程序和个人 INI。保留原旧语音素材、根目录加载器以及其他 Mod；不要删除整个 `mods/` 或 `voice/` 目录。
