# 本地候选验收与回退

此候选尚未由用户在游戏中验收。本轮 options 包仍待最终提交、构建和打包；生成后供用户手动验收。本地构建和 ZIP 核对不代表已通过游戏测试；不包含安装或启动游戏操作。只在 `sora_1st.exe` SHA256 为 `9585d3d993874d65156aba633c00b8a25faab3afde8953a8a183c80fb8f657ac` 且已有 sora1looseload v0.2.0 的环境中手动验收。

## 安装准备

1. 退出游戏，备份 `mods/VoiceRandomizer/`、`voice/wav/voice_randomizer/voice_randomizer.ini`、`voice/wav/voice_randomizer/克萝赛MOD设置.exe`。特别保留原 DLL 和编辑器，便于回退。保留根目录现有的 `xinput1_4.dll`。
2. 已有兼容候选且素材完整时，解压 `dist/20261020-options/VoiceRandomizer-options-candidate-module-update.zip` 到游戏目录，按原目录合并。包内只有 `mods/VoiceRandomizer/VoiceRandomizer.dll`、`mods/VoiceRandomizer/sora_mod.ini` 和 `voice/wav/voice_randomizer/克萝赛MOD设置.exe`；不会覆盖用户 INI。
3. 首次安装或需恢复原素材时，改用 `VoiceRandomizer-options-candidate-install.zip`。它包含新默认 INI，可能覆盖同名个人配置；安装前备份，安装后恢复自己的 INI。更新包和完整安装包二选一。
4. 默认配置先测试单声道规则与界面。双声道测试放在最后，再把 `dist/20261020-stereo/VoiceRandomizer-stereo-assets.zip` 解压到游戏目录，保持 ZIP 内 `voice/wav/voice_randomizer/assets/stereo_lr/` 与 `stereo_rl/` 路径。该包含 1,648 个 WAV，解压约 1.055 GB。

旧 INI 不必手工补齐新键：模块对缺失键采用模板默认值，软保底和双声道默认关闭。安装包中的新设置编辑器名为 `克萝赛MOD设置.exe`（构建目录的产物名为 `KloseVoiceSettings.exe`），可以读取旧 INI；保存时会补上缺失的新字段并保留现有注释和不相关设置。若由设置编辑器保存，约 1 秒后后续播放使用新设置；左右音量变化应用于之后创建的声源，切换 `ReplacementSet` 要重启游戏。

## 手动验收顺序

| 顺序 | 设置与操作 | 预期表现 |
| --- | --- | --- |
| 普通规则 | 确认模块初始化；依次设 `Mode=new`、`old`，然后设 `random` 并关闭两种旧规则、将 `OldPercent` 设为 0 和 100 | `new` 播游戏新版，`old` 播可用旧版；random 的 0/100 分别只选新/旧。旧素材不可用时回到游戏配音。 |
| 硬保底与捕获明光 | 单独打开硬保底测试一次未中后的下一条；再关闭硬保底、打开捕获明光，按目标版本设置相反的基础概率连续播放 | 硬保底下一条命中目标；捕获明光按原规则计数并在第三次未中后的下一次触发。分别将目标设为 new/old 检查镜像行为。 |
| 软保底 | 为单独观察软保底，关闭硬保底与捕获明光，设 `Mode=random`、`GuaranteeTarget=new`、`OldPercent=100`、`SoftPityEnabled=1`、`SoftPityStart=2`、`SoftPityStep=10` | 前两次目标概率为 0%，所以都未中；第三次目标概率为 10%。若该次再未中，第四次为 20%。再用基础目标概率 50%、Start=2、Step=10 对照：两次未中后下次为 60%，再未中后下次为 70%。命中目标后软计数回到 0；硬保底或捕获明光若提前命中，也会清零。 |
| 规则状态 | 在随机模式积累未中后，仅改 `SoftPityEnabled`、`Start` 或 `Step`；之后再改 `GuaranteeTarget`、`GuaranteeEnabled` 或 `CapturingRadianceEnabled` | 只改软保底参数时只清软计数；改目标、硬保底或捕获明光开关时清全部规则计数。基础概率和 Overlay 选项变化不清计数。切换非随机模式、关闭语音总开关或开启双声道会暂停随机/交替/保底计数。 |
| Overlay | 播放多条语音；在 `MaxEntries=1`、`10` 和 `50` 间切换，再调整透明度和歪标识比例；设 `HideOnOtherVoice=1`，触发其他角色语音后再触发克萝赛语音 | 默认显示最近 10 条，最多保留 50 条。改变条数不改变头像大小或间距；超过十条时列表向上延伸，画面外上部被裁剪。透明度 0 完全不透明、100 完全隐藏；歪标识独立缩放且左上角固定。成功播放 kind=2 的其他角色语音会隐藏 Overlay，克萝赛语音恢复显示，历史保留。 |
| 新设置编辑器 | 打开新 `克萝赛MOD设置.exe`，分别调整软保底、Overlay 与双声道字段并保存；在预览中把 `MaxEntries` 调到 1、10、50，退出后重新打开检查配置 | 新界面显示新字段，保存值可读回且既有选项保留。预览中的头像大小和间距不随条数变化，超出预览区域的上部被裁剪。更新包中的设置编辑器已替换为从修改后的公开源码重新构建的版本。 |
| 双声道（最后） | 安装独立素材 ZIP；设 `Enabled=1`、`Stereo/Enabled=1`、`SwapChannels=0`、`LeftVolume=0`、`RightVolume=100`，等约 1 秒后播放可用语音。再将音量改为左 100、右 0，等设置重读并播放新语音；最后切换 `SwapChannels=1`，用两组音量设置重测 | 默认左新版、右旧版；左静音时只听右侧旧版，右静音时只听左侧新版。交换后为左旧版、右新版：左静音时应只听右侧新版，右静音时应只听左侧旧版。音量只应用于之后创建的声源，不改变已播放语音。播放记录应显示新旧双头像。 |

双声道由两组固定 PCM 2 声道 WAV 提供：`stereo_lr` 和 `stereo_rl`。改变交换或左右音量不需重写素材。实现保留游戏原高层语音请求与播放路径，并在原生 SourceVoice 创建后应用左右音量；实际设备左右输出、耳机/扬声器和游戏场景的路由仍需用户确认。缺少双声道素材时回到游戏语音。不要将此项记为通过，直到左右声道听测完成。

普通语音规则、软保底、Overlay 和设置编辑器均通过后，才装双声道素材包。候选输出在 [source/THIRD_PARTY.md](source/THIRD_PARTY.md) 中说明；双声道素材留在本地，不上传、不随公开源码包发布。

## 回退

先退出游戏。若使用更新包，只需将备份的 `mods/VoiceRandomizer/VoiceRandomizer.dll`、`mods/VoiceRandomizer/sora_mod.ini`、`voice/wav/voice_randomizer/克萝赛MOD设置.exe` 和用户 INI 恢复到安装前版本。若使用完整安装包，还要恢复安装前的用户 INI。若双声道包已解压，只删除此次新增的 `voice/wav/voice_randomizer/assets/stereo_lr/` 和 `stereo_rl/`；原 `assets/old/`、UI 图、其他 Mod、根目录 `xinput1_4.dll` 与游戏文件保持原样。
