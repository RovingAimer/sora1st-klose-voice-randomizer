# 空之轨迹 the 1st 科洛丝新旧语音随机 MOD v1.2.0

给科洛丝的语音加一点抽卡体验：同一句台词每次播放时，在新版和旧版配音之间重新选择。

包含 824 条正式旧版语音，覆盖主线、战斗、原野和主动语音。基础概率默认各 50%，可分别开关保底和捕获明光，也可将目标反转为旧版：抽到新版算“歪”，随后保底旧版，捕获明光同样出旧版。其他角色仍用游戏配音。

左侧显示最近 10 条科洛丝语音记录，最新记录从底部进入，并绘制对应新旧头像和“歪 / 捕获明光”标识。

安装：退出游戏，将 ZIP 内的 DLL、资源目录和《克萝赛随机语音MOD.txt》解压到 `sora_1st.exe` 所在目录。双击资源目录内的“克萝赛MOD设置.exe”即可通过图形界面调整配置。卸载时退出游戏，移除本 MOD 的 DLL、资源目录和说明文本。

面向已核验的 Windows x64 / DirectX 11 版本，更新游戏后可能需要适配。与其他同名 xinput1_4.dll MOD 不能直接合并。旧配音保留原时长，部分剧情同步可能与新版不同；反馈请附 `voice_randomizer/voice_randomizer.log`。

旧语音资源来源于 B 站 UP 主 **Mini_Lom233**。感谢 MinHook、sora1looseload 的公开工作。
