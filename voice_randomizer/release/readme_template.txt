克萝赛随机语音MOD v1.2.0

【中文】

为《空之轨迹 the 1st》的克萝赛语音增加新旧版随机播放，包含 824 条正式旧版语音，并显示最近 10 条播放记录。默认基础概率各 50%，启用保底和捕获明光；其他角色保持游戏配音。

安装：退出游戏，将 xinput1_4.dll、voice_randomizer 文件夹和本说明解压到 sora_1st.exe 所在目录，再正常启动游戏。若已有其他 MOD 的同名 DLL，请勿直接覆盖。

配置：双击 voice_randomizer 文件夹内的“克萝赛MOD设置.exe”，在图形界面中调整并保存；也可直接修改同目录的 INI 文件。

卸载：退出游戏，移除本 MOD 的 xinput1_4.dll、voice_randomizer 文件夹和本说明。

兼容与反馈：适用于已核验的 Windows x64 / DirectX 11 游戏版本，游戏更新后可能需要适配。旧语音保留原时长，部分剧情同步可能存在差异。反馈问题时请附上 voice_randomizer/voice_randomizer.log。

素材与致谢：旧语音资源来源于 B 站 UP 主 Mini_Lom233。加载方式与文件入口研究参考 sora1looseload；Hook 使用 MinHook v1.3.4，完整许可证附于文末。

【English】

This mod randomly selects new or legacy voice lines for Klose in Trails in the Sky 1st Chapter. It includes 824 legacy lines and displays the latest 10 playback records. The default base chance is 50% for each version, with Guarantee and Capturing Radiance enabled. Other characters keep their game audio.

Installation: close the game and extract xinput1_4.dll, the voice_randomizer folder and this file beside sora_1st.exe, then launch the game normally. Do not overwrite a DLL with the same name belonging to another mod.

Configuration: open 克萝赛MOD设置.exe inside the voice_randomizer folder, adjust your settings and click Save. The editor supports English. You can also edit the INI in the same folder.

Uninstallation: close the game and remove this mod's xinput1_4.dll, voice_randomizer folder and this file.

Compatibility and feedback: supports the verified Windows x64 / DirectX 11 game build; game updates may require a mod update. Legacy lines retain their original durations, so story timing may differ. Include voice_randomizer/voice_randomizer.log when reporting issues.

Credits: legacy voice resources were sourced from Bilibili creator Mini_Lom233. Loading and file-entry research references sora1looseload. Hooks use MinHook v1.3.4; its full license follows below.
