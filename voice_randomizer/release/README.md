# 克萝赛随机语音 MOD v1.2.0

为《空之轨迹 the 1st》提供新旧语音随机播放和最近 10 条记录，包含 824 条正式旧版语音。旧语音资源来源于 B 站 UP 主 **Mini_Lom233**。

发布包根目录包含：

```text
xinput1_4.dll
voice_randomizer/
  克萝赛MOD设置.exe
  voice_randomizer.ini
克萝赛随机语音MOD.txt
```

退出游戏，将包内内容解压到 `sora_1st.exe` 所在目录。双击 `voice_randomizer/克萝赛MOD设置.exe` 进行图形化设置，调整后点击保存。程序无需额外运行库，支持中英文，也可以继续手动编辑 INI。

《克萝赛随机语音MOD.txt》包含独立的中文和英文使用说明，文末保留完整 MinHook 许可证。INI 仅保留配置相关说明，每项中文段落后接英文段落。

构建、测试和校验信息另存于开发目录；本文件不进入运行 ZIP。
