# v1.2.0 — 图形设置程序

- INI 同级新增约 210 KB 的原生 Windows 设置程序，无需额外运行库或安装步骤。
- 支持中英文界面，覆盖语音模式、概率、目标版本、两层机制、记录 UI、素材集及日志全部 13 项设置。
- 提供记录区域位置预览、恢复默认、重新读取、未保存提示和数值范围检查。
- 保存保留 INI 注释与未知配置，检测外部修改冲突，以临时文件完成整份替换并处理短暂文件占用。
- 缺少 INI 时可用内嵌的完整配置模板创建；正式语音、UI 图片和语音 DLL 沿用已验证版本。
- 说明文本仍分为中文、英文两部分，文末保留 MinHook 许可证；旧语音来源为 B 站 UP 主 Mini_Lom233。

# v1.1.0 — 可配置随机机制与精简运行包

- 新增 `GuaranteeTarget=new/old`，同步反转保底、捕获明光和【歪】标识。
- 新增 `GuaranteeEnabled`、`CapturingRadianceEnabled`，两层机制可以独立开关。
- 修改目标或机制开关时立即清空两种累计状态；每次选择保留一致的规则快照与日志配置代数。
- INI 仅保留配置说明，每项先写中文段落再写英文段落，包含规则、取值范围及重载行为。
- ZIP 根目录为 `xinput1_4.dll`、`voice_randomizer` 与《克萝赛随机语音MOD.txt》，内含 824 条正式旧音频及四张 UI 图片。
- 简明使用说明完整分为中文、英文两部分，文末保留完整 MinHook 许可证；不包含安装脚本或开发工具。
- 旧语音来源注明为 B 站 UP 主 Mini_Lom233。
- 保持默认新版目标、基础旧版概率 50%、两机制开启和原 UI 位置；旧音频与用户图片字节保持不变。
- 验证了两个目标与四种开关组合、配置重载、并发规则状态、真实 Windows INI 解析及语音 hook / DX11 回归。

# v1.0.0 — 首次发布

- 收录 824 条科洛丝正式旧版配音，覆盖剧情、战斗、原野和主动语音。
- 每次播放重新选择版本，支持基础 50% 概率、保底和捕获明光。
- 新旧配音使用独立缓存名，重复台词也可切换版本。
- 游戏内显示最近 10 条科洛丝语音，最新记录从底部进入。
- 包含新版/旧版头像，以及捕获明光/歪两种图片标识。
- 配置默认启用正式旧版语音，沿用发布者调整的 UI 位置；不包含测试提示音。
- 提供双击安装/卸载、游戏版本检查、同名 DLL 保护和文件校验清单。

此版本沿用已实机验证的语音和 UI 实现；正式旧语音保留素材原时长。游戏版本、覆盖范围和使用说明见 README.md。
